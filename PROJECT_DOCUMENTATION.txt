DATABASE SCHEMA
================================================================================

1. USER MODEL (users collection)
   Fields:
   - _id: ObjectId (Primary key)
   - name: String (1-100 characters, required)
   - email: String (Unique, lowercase, valid format, required)
   - password: String (Min 6 chars, hashed, required, hidden by default)
   - isAdmin: Boolean (Default: false)
   - createdAt: Date (Auto-set to current date)
   
   Methods:
   - matchPassword(enteredPassword): Compare hashed password
   
   Hooks:
   - Pre-save: Hash password using bcryptjs (salt rounds: 10)

2. SLOT MODEL (slots collection)
   Fields:
   - _id: ObjectId (Primary key)
   - slotNumber: String (Unique, e.g., "A1", "B5", format: [A-E][1-5])
   - section: String (A, B, C, D, or E)
   - position: Number (1-5 within each section)
   - isBooked: Boolean (Default: false)
   - bookedBy: ObjectId (Reference to User)
   - createdAt: Date (Auto-set)
   
   Total Slots: 25 (5 sections × 5 slots per section)

3. BOOKING MODEL (bookings collection)
   Fields:
   - _id: ObjectId (Primary key)
   - userId: ObjectId (Reference to User, required)
   - slotId: ObjectId (Reference to Slot, required)
   - slotNumber: String (e.g., "A1", for quick reference)
   - bookingDate: Date (Date of booking, required)
   - bookingTime: String (HH:MM format, 24-hour, required)
   - duration: Number (1-24 hours, default: 1)
   - status: String (active|completed|cancelled, default: active)
   - createdAt: Date (Auto-set)
   - updatedAt: Date (Auto-set)

API ENDPOINTS
================================================================================

BASE URL: http://localhost:5000/api

AUTHENTICATION ROUTES (/auth)
────────────────────────────────────

POST /auth/register
  Description: Register a new user
  Request Body:
    {
      "name": "string",
      "email": "string",
      "password": "string (min 6)",
      "confirmPassword": "string"
    }
  Response:
    {
      "success": true,
      "message": "User registered successfully",
      "token": "JWT_TOKEN",
      "user": {
        "id": "ObjectId",
        "name": "string",
        "email": "string",
        "isAdmin": false
      }
    }
  Errors:
    - Missing fields (400)
    - Passwords don't match (400)
    - Email already registered (400)

POST /auth/login
  Description: Login with email and password
  Request Body:
    {
      "email": "string",
      "password": "string"
    }
  Response:
    {
      "success": true,
      "message": "Login successful",
      "token": "JWT_TOKEN",
      "user": {
        "id": "ObjectId",
        "name": "string",
        "email": "string",
        "isAdmin": boolean
      }
    }
  Errors:
    - Invalid credentials (401)
    - User not found (401)

POST /auth/setup-admins
  Description: Setup three admin users (internal use only)
  Request Body: {} (empty)
  Response:
    {
      "success": true,
      "message": "Admin users setup completed",
      "admins": [
        {
          "name": "string",
          "email": "string",
          "isAdmin": true,
          "status": "Created|Updated to Admin"
        }
      ]
    }
  Note: Deletes all existing admins before creating new ones


SLOTS ROUTES (/slots)
────────────────────────────────────

GET /slots
  Description: Get all parking slots
  Authentication: Required (Bearer token)
  Response:
    {
      "success": true,
      "message": "Slots retrieved successfully",
      "slots": [
        {
          "_id": "ObjectId",
          "slotNumber": "A1",
          "section": "A",
          "position": 1,
          "isBooked": false,
          "bookedBy": null,
          "createdAt": "ISO_DATE"
        }
      ]
    }
  Note: Auto-initializes 25 slots if none exist

POST /slots/initialize
  Description: Initialize parking slots (run once)
  Authentication: Not required
  Response:
    {
      "success": true,
      "message": "25 slots created successfully",
      "slots": [...]
    }
  Errors:
    - Slots already initialized (400)

POST /slots/reset
  Description: Reset all slots (admin only)
  Authentication: Required (Admin)
  Response:
    {
      "success": true,
      "message": "All slots reset to available"
    }
  Errors:
    - Admin access required (403)


BOOKINGS ROUTES (/bookings)
────────────────────────────────────

POST /bookings
  Description: Create a new booking
  Authentication: Required (Bearer token)
  Request Body:
    {
      "slotId": "ObjectId",
      "bookingDate": "YYYY-MM-DD",
      "bookingTime": "HH:MM",
      "duration": 1-24
    }
  Response:
    {
      "success": true,
      "message": "Booking created successfully",
      "booking": {
        "_id": "ObjectId",
        "userId": "ObjectId",
        "slotId": "ObjectId",
        "slotNumber": "A1",
        "bookingDate": "ISO_DATE",
        "bookingTime": "14:30",
        "duration": 2,
        "status": "active",
        "createdAt": "ISO_DATE",
        "updatedAt": "ISO_DATE"
      }
    }
  Errors:
    - Missing fields (400)
    - Slot already booked (400)
    - Slot not found (404)

GET /bookings
  Description: Get user's bookings or all bookings (if admin)
  Authentication: Required (Bearer token)
  Response:
    {
      "success": true,
      "message": "Bookings retrieved successfully",
      "bookings": [...]
    }

GET /bookings/user/:userId
  Description: Get specific user's bookings (admin only)
  Authentication: Required (Admin)
  Response: Bookings array

DELETE /bookings/:bookingId
  Description: Cancel a booking
  Authentication: Required (Bearer token)
  Restrictions: User can only cancel own bookings, admins can cancel any
  Response:
    {
      "success": true,
      "message": "Booking cancelled successfully"
    }
  Errors:
    - Booking not found (404)
    - Access denied (403)

AUTHENTICATION & AUTHORIZATION
================================================================================

JWT Token Structure:
  - Header: { "alg": "HS256", "typ": "JWT" }
  - Payload: {
      "id": "user_id",
      "email": "user_email",
      "isAdmin": boolean,
      "iat": timestamp,
      "exp": timestamp (7 days)
    }
  - Signature: HMAC-SHA256

Token Storage:
  - Stored in browser's localStorage
  - Key: "token"
  - Also stored: "user" (JSON stringified user object)

Token Usage:
  - Sent in Authorization header: "Bearer <token>"
  - Verified on each API request
  - Invalid/expired tokens return 401 Unauthorized

Admin Validation:
  1. User registers or logs in
  2. Backend checks if email in admin whitelist
  3. Backend checks if isAdmin flag = true in database
  4. Both conditions required for admin access
  5. Token includes isAdmin flag
  6. Frontend checks isAdmin flag to show/hide admin features
  7. Backend enforces admin-only routes

TROUBLESHOOTING
================================================================================

Issue: "Cannot connect to MongoDB"
  Solution:
  - Ensure MongoDB is running
  - Check connection string in .env file
  - Verify MongoDB port (default: 27017)
  - Check firewall settings

Issue: "Port 5000 already in use"
  Solution:
  - Change PORT in .env file
  - Kill process on port 5000: netstat -ano | findstr :5000
  - Or use different port in server.js

Issue: "JWT token invalid"
  Solution:
  - Clear localStorage (browser dev tools)
  - Log out and log back in
  - Check JWT_SECRET matches in backend
  - Ensure token hasn't expired (7 days)

Issue: "Admin access denied"
  Solution:
  - Verify email is in whitelist (auth.js)
  - Check isAdmin flag in database
  - Clear localStorage and re-login
  - Check user has admin privileges

Issue: "Cannot book slot"
  Solution:
  - Ensure you're logged in
  - Check slot is available (not red/booked)
  - Verify booking date is today or future
  - Check time format (HH:MM, 24-hour)
  - Check duration is 1-24 hours
